# Yordanos Kassa — Portfolio

Personal portfolio for Yordanos Kassa, a Columbia University computer
science–mathematics and astrophysics student working across backend
engineering, AI retrieval, and formal verification.

## Featured work

- **PatchProof** — specification-aware code verification across CLI, VS Code,
  GitHub Apps, FastAPI, PostgreSQL, and AWS.
- **Repofy** — repository collaboration platform built with React, Express,
  PostgreSQL, and Supabase.
- **PaperMind AI** — semantic search and summarization for research papers.
- **Research** — Lean 4 theorem retrieval, faithful proof-step explanations,
  and multimessenger astrophysics.

## Local development

```bash
npm install
npm start
```

Build the production bundle with:

```bash
npm run build
```

The live site is hosted at
[my-portfolio-gray-seven-42.vercel.app](https://my-portfolio-gray-seven-42.vercel.app/).
